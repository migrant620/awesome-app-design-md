# Contributing to Awesome App DESIGN.md

Thanks for helping keep this collection accurate.

Each entry pairs a DESIGN.md with a working, interactive recreation of the app and its source code, so new entries are produced by the maintainer to keep them at the same standard. Pull requests that add entries can't be accepted.

## Report a correction

If a colour, size, spacing value or description doesn't match the app:

1. [Open an issue](https://github.com/migrant620/awesome-app-design-md/issues) naming the app and the screen.
2. Describe what you see in the app and what the entry says. A screenshot of the app helps.
3. Mention the app version and platform if you know them.

Problems with a live demo or its source code can be reported here or in the app's own repository.

## Request an app

[Open a request](https://github.com/migrant620/awesome-app-design-md/issues/new?title=App%20request%3A%20) with the app name and the flows you'd most like to see.
