# Tiimo — DESIGN.md

Visual day planner. Soft off-white calm, time-of-day tints instead of clock times, serif moments, and a lavender arc that shows focus time passing.

[▶ Live demo](https://tiimo-ui.edgeone.cool) · [Source code](https://github.com/migrant620/tiimo-ui) · [DESIGN.md](DESIGN.md) · [Design notes](https://github.com/migrant620/tiimo-ui#design-notes)

## At a glance

| | |
|---|---|
| Surfaces | `#FCFCFC` page, `#F6F5F4` sheets, white controls on a soft shadow |
| Accent | Lavender `#9F85FF` — selected day, save, marker chips, focus progress |
| Time of day | Morning `#FFF2ED` · Afternoon `#F0F3FF` · Evening `#EFE8FF` · Anytime neutral |
| Type | Serif for moments (date, focus title, timer); Roboto for everything you act on; tracked 12.3 dp section labels |
| Signature | Focus arc grows clockwise from twelve o'clock, one turn per task |

## Use it

Copy [`DESIGN.md`](DESIGN.md) into your project root and ask your AI coding agent to build a screen in this style — for example: *"Build a daily plan screen with time-of-day sections following DESIGN.md."*
