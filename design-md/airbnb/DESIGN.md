# Airbnb — DESIGN.md

Photo-led white cards on a plain page, a near-black ink with a single rose accent, and a search sheet that reads as one sentence in three clauses. Covers the first batch (Explore, the search sheet, results, listing detail, the photo viewer and the sign-in sheet).

[▶ Live demo](https://airbnb-ui.edgeone.cool) · [Source code](https://github.com/migrant620/airbnb-ui) · [DESIGN.md](DESIGN.md) · [Design notes](https://github.com/migrant620/airbnb-ui#design-notes)

## At a glance

| | |
|---|---|
| Surfaces | White `#FFFFFF` page, cards, sheets and floating controls; photography is the only strong colour |
| Accent | Rose `#FF385C` for the selected tab, heart and guest-favourite badge; `#D70466` Reserve is the one darker control |
| Structure | Explore feed (All · Homes · Experiences · Services) over a 56 dp search pill; a three-clause search sheet (Where, When, Who) |
| Type | Plus Jakarta Sans for text, Roboto Medium for numerals (prices, ratings, dates, counts); Cereal substituted and width-matched |
| Signature | The photograph is the only loud element; everything else steps back so it can |

## Use it

Copy [`DESIGN.md`](DESIGN.md) into your project root and ask your AI coding agent to build a screen in this style — for example: *"Build an Explore screen with a search pill and two rows of listing cards following DESIGN.md."*
