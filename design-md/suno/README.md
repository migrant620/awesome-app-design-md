# Suno — DESIGN.md

AI music creation. Warm paper canvas over a drifting aura, dashed add-on pills around a single prompt, a pink-to-orange gradient saved for the moment of making, and a player painted from the cover art.

[▶ Live demo](https://suno-ui.edgeone.cool) · [Source code](https://github.com/migrant620/suno-ui) · [DESIGN.md](DESIGN.md) · [Design notes](https://github.com/migrant620/suno-ui#design-notes)

## At a glance

| | |
|---|---|
| Surfaces | Warm `#F7F4EF` paper with `#101012` ink; fields `#EEEBE7`, controls `#E5E2DD` |
| Accent | Pink `#FF399C` → orange `#FF702C` for Create and the model selector; blue `#0089FF` for selected secondary actions |
| Structure | One free-text prompt; Lyrics, Styles and Audio as optional dashed pills; Advanced mode opens full editors |
| Type | Roboto throughout (28 dp headings, medium pills); Instrument Serif for promotional moments |
| Signature | Full player turns dark and takes its colour from the cover |

## Use it

Copy [`DESIGN.md`](DESIGN.md) into your project root and ask your AI coding agent to build a screen in this style — for example: *"Build a creation screen with a single prompt and optional add-on pills following DESIGN.md."*
