# Luma — DESIGN.md

Event discovery and hosting. A pastel welcome wall of frosted glass cards, a warm pink-to-orange brand gradient, a date-grouped card feed, and a deep indigo detail page.

[▶ Live demo](https://luma-ui.edgeone.cool) · [Source code](https://github.com/migrant620/luma-ui) · [DESIGN.md](DESIGN.md) · [Design notes](https://github.com/migrant620/luma-ui#design-notes)

## At a glance

| | |
|---|---|
| Surfaces | White home and discover, `#F5F6F8` create canvas, `#F4F5F6` tab bar |
| Accent | Magenta `#DA60BF` → pink `#F65A90` → orange `#F3AB5A`, reserved for the welcome hero and get-started button |
| Welcome | Pastel gradient (`#FFE0E8` → `#FEECD7` → `#E3F0EA` → `#CEF0F5`) fading to white behind frosted event cards |
| Detail | Deep indigo `#0A0922` with white type and a rounded cover card |
| Type | Plus Jakarta Sans throughout; large extra-bold titles, grey weight-based hierarchy |
| Signature | Round gradient get-started button and the soft "Create Event" capsule above the tab bar |

## Use it

Copy [`DESIGN.md`](DESIGN.md) into your project root and ask your AI coding agent to build a screen in this style — for example: *"Build an event discovery feed with date-grouped cards following DESIGN.md."*
