# Structured — DESIGN.md

A grey page holding one white day: a vertical timeline spine with a disc per task, time labels down the left gutter, and a single coral accent reserved for planning and action. Covers the first batch (the day timeline in its first-run, populated, completed and delete-confirmation states, the two-step task editor, the task detail sheet, the inbox tab and the settings tab).

[▶ Live demo](https://structured-ui.edgeone.cool) · [Source code](https://github.com/migrant620/structured-ui) · [DESIGN.md](DESIGN.md) · [Design notes](https://github.com/migrant620/structured-ui#design-notes)

## At a glance

| | |
|---|---|
| Surfaces | Page `#F2F2F5`, white `#FFFFFF` sheets and controls, `#EBEBEB` bottom bar |
| Accent | Coral `#F49F99` — planned discs, action cards, the editor's selection pill, the completion ring; `#FDECEB` is its wash |
| Structure | One unbroken spine down the day: pink `#F49F99` dashes between planned rows, a grey stub into unscheduled ones, a black "now" marker |
| Type | Roboto in twelve static instances, one per role, from 10.2 dp gutter labels to a 23 dp month header |
| Signature | Completed tasks stay on the spine and take a line-through rather than leaving the day |

## Use it

Copy [`DESIGN.md`](DESIGN.md) into your project root and ask your AI coding agent to build a screen in this style — for example: *"Build a day timeline with one spine, a disc per task and gutter time labels following DESIGN.md."*
